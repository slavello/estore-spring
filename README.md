# E-Store

Приложение для управления деятельностью **сети магазинов электроники**.

Backend на Spring Boot предоставляет REST API (Swagger), данные хранятся в PostgreSQL, веб-интерфейс — минимальная HTML/JS-страница для проверки всех функций.

## Технологический стек

- Язык программирования: Java 11
- Фреймворки: Spring Boot 2.7, Spring Web, Spring Data JPA, Spring Hibernate
- СУБД: PostgreSQL
- Документация API: springdoc-openapi (Swagger UI)
- Frontend: HTML/CSS/JS

## Особенности

* Проект состоит из двух микросервисов: estore-backend и estore-frontend
* Таблицы: **Сотрудники**, **Электротовары**, **Покупки** (CRUD), **Должности**, **Тип электроники**, **Магазин**, **Тип покупки**.
* Сортировка реестра покупок по дате покупки.
* **Проверка наличия товара в магазине перед покупкой**: если товара нет (нет остатка либо товар архивный), то запись о покупке **не создаётся**.
* Отчёты:
    * лучшие сотрудники по каждой должности по критерию:
        * Наибольшее количество проданных товаров;
        * Наибольшая сумма проданных товаров, руб.;
    * лучший сотрудник выбранной должности по продаже выбранного товара;
    * сумма денежных средств, полученная **через оплату выбранным способом** (по всей сети или по магазину).
* Импорт данных из отдельного CSV-файла, либо из zip-архива с CSV-файлами.

## Запуск

Проект состоит из двух микросервисов и собирается из корня репозитория:

* **estore-backend** — REST API + Swagger, порт `8080`, работает с PostgreSQL;
* **estore-frontend** — статический веб-интерфейс (HTML/CSS/JS), порт `8081`.

Сборка и запуск тестов:

```bash
mvn clean package
```

После сборки появятся два исполняемых jar:

* `estore-backend/target/estore-backend-1.0-SNAPSHOT.jar`
* `estore-frontend/target/estore-frontend-1.0-SNAPSHOT.jar`

Запуск: 

```bash
java -jar estore-backend/target/estore-backend-1.0-SNAPSHOT.jar # Запуск бэкенда
java -jar estore-frontend/target/estore-frontend-1.0-SNAPSHOT.jar # Запуск фронтенда
```

* http://localhost:8081/ — веб-интерфейс
* http://localhost:8080/swagger-ui.html — Swagger UI (API)

### Настройка через переменные окружения

#### Frontend

| Переменная | По умолчанию | Описание     |
| ---------- | ------------ | ------------ |
| `PORT`     | `8081`       | Порт сервиса |


> [!WARNING]
> Адрес бэкенда для веб-интерфейса задаётся в `app.js` константой `API_BASE`
(по умолчанию `http://localhost:8080`) или глобальной переменной `window.API_BASE`
перед загрузкой скрипта.

#### Backend

| Переменная    | По умолчанию                              | Описание                        |
| ------------- | ----------------------------------------- | ------------------------------- |
| `PORT`        | `8080`                                    | Порт сервиса                    |
| `DB_URL`      | `jdbc:postgresql://localhost:5432/estore` | Строка подключения к БД         |
| `DB_USERNAME` | `postgres`                                | Логин пользователя баз данных   |
| `DB_PASSWORD` | `root`                                    | Пароль пользователя баз данных  |
| `DDL_AUTO`    | `update`                                  | Режим генерации схемы Hibernate |

## Импорт из файлов

Реализован импорт CSV файла по каждой таблице и импорт ZIP-файла с CSV файлами.
### Импорт из ZIP

Архив содержит CSV-файлы для импорта (разделитель `;` или `,`, кодировка UTF-8 или Windows-1251, заголовок обязателен). Нераспознанные CSV файлы пропускаются.
- Имя файла распознаётся по псевдонимам.
* Ссылки можно указывать **наименованием** либо **идентификатором**.
* При импорте покупок выполняется проверка наличия товара. Если товара нет в наличии, то покупка пропускается с ошибкой.
* Колонка `ID` необязательна.

Примеры импортируемых файлов - в папке [`estore-backend/sample-data/`](estore-backend/sample-data/).
